## 集成测试

### 流程：任务已是最新时跳过重写

> 涉及模块：`game_auto_start`、`main`（启动校准）

- [x] **前置**：设置中开启「随游戏自动启动」并保存；关闭 AFA。
- [x] **操作**：直接启动 AFA（不经游戏触发），待主界面出现后退出；再启动一次。
- [x] **预期**：第二次启动的日志出现 `[GameAutoStart] 计划任务已匹配，跳过重写`，**不出现** `计划任务字段漂移：principal_user`，也不出现 `计划任务已创建或更新`。

### 流程：用户名与计算机名相同的环境（如有条件）— 跳过：当前无用户名与计算机名相同的测试环境

> 涉及模块：`game_auto_start`

- [ ] **前置**：在 Windows 用户名与计算机名相同的机器上（例如计算机名 `LENOVO`、用户 `lenovo`）开启「随游戏自动启动」。
- [ ] **操作**：连续两次直接启动 AFA。
- [ ] **预期**：第二次日志为 `计划任务已匹配，跳过重写`，无 `principal_user` 漂移。

### 流程：任务缺失时重新创建

> 涉及模块：`game_auto_start`、Windows 任务计划程序

- [x] **前置**：「随游戏自动启动」已开启。
- [x] **操作**：在任务计划程序库根目录删除 `ArknightsFrameAssistant-AutoStartWithGame-<SID>` 任务，再直接启动 AFA。
- [x] **预期**：日志出现 `计划任务已创建或更新：<游戏路径>`；任务计划程序中任务重新出现，其「常规」页运行用户为当前用户。

### 流程：随游戏启动仍然生效

> 涉及模块：`game_auto_start`、`main`

- [x] **前置**：「随游戏自动启动」已开启，AFA 与游戏均未运行。
- [x] **操作**：从游戏启动器正常启动明日方舟。
- [x] **预期**：AFA 自动启动，日志出现 `本次启动来源：随游戏自动启动（--game-autostart）`。

##### 异常路径

- [x] **异常**：修改设置中的游戏路径并保存后，再直接启动 AFA → **预期**：日志出现 `计划任务字段漂移：trigger`（或保存时已更新任务），任务被重写；之后再启动一次显示 `跳过重写`。
