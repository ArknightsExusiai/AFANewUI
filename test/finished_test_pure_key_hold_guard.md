# 测试清单：`pure_key_hold_guard`

> 对应更改：把「按住热键时动作只触发一次」从**阻塞等待**（`PureKeyWait` = 挂住热键线程直到物理松开）改为**按住去重状态机**（`HoldGuard`）。
> 物理抬起由 `X Up` 变体即刻结束按住周期，兜底定时器（25ms）负责物理态校验与「抬起事件丢失」自愈；带松开尾部的动作（如「模拟左键点击」的 `{LButton Up}`）改为按住周期结束时的收尾回调。
> 同时修正 `KeyForward._LastForwardDownTick` 的双重语义：它只服务 Up 补发回环检测，「按住时长」日志改由按住周期起始 tick 给出。

### 功能点：日志口径

- [x] **预期**：松开后出现 `[DEBUG] [HoldGuard] 按住周期结束：key=X，按住 NNNNms`；若由兜底路径结束，则出现 `[DEBUG] [HoldGuard] 兜底结束按住周期：key=X，按住 NNNNms（物理态已抬起或跳变自愈）`，且 N 与真实按住时长一致（不再是「距上次按下」）
- [x] **预期**：**不再出现** `[KeyForward] 等待物理松开已 Ns`（旧 `PureKeyWait` 的日志已整体移除）
- [x] **预期**：透传日志形如 `透传 key=X（按住 NNNNms）`（该时长口径是「距上次真实按下」，不是本次按住时长；本次按住时长以上一条 `HoldGuard` 日志为准）

### 流程 1：issue #286 原始复现（本轮的核心回归点）

> 涉及模块：`hotkey_actions`、`hotkey_service`

- [x] **前置**：进入任意关卡，守卫开启（`InLevelGuard=1`），已绑定「按下时暂停」（默认 `f`）与「切换倍速」（默认 `d`）

- [x] **预期**：按住 `d` 期间，`f` **每次按下都能触发暂停切换**（旧实现下 `f` 会在 `d` 松开前完全失效）
- [x] **预期**：松开 `d` 后 `f` 立即可用，无需等待
- [x] **预期**：日志里 `d` 的 `透传` 行与 `f` 的 `ActionPressPause 执行` 行交替出现，`f` 不会被 `MaxThreadsPerHotkey` 静默挡掉

> 涉及模块：`hotkey_actions`（`HoldGuard.Poll`）

- [x] **前置**：无法脚本化构造「驱动层吞掉抬起」，用**日志观察**代替：长按某键后直接关闭该键的输入源（如拔掉/关闭该键所在的键盘，或在键盘软件里禁用该键）
- [x] **操作**：如此制造一次「OS 认为键仍按下」的状态，然后重新启用该键并按一下
- [ ] **预期**：若该键产生新的按下沿（down→up→down 跳变），日志出现 `[WARN] [HoldGuard] 按住周期自愈：key=X，检测到抬起事件丢失后的新按下沿`，该键立刻恢复可用
- [ ] **预期**：若物理态始终显示按下且再无跳变，则该键的按住周期常驻、**该键**不再触发，但**其余所有键完全不受影响**（这是已接受的取舍：不做时长硬上限）
- [x] **预期**：全程 `HookHealth` 心跳快照里 `depth=0`、`inflight=[]`（按住周期不再占用线程）

##### 异常路径

- [x] **异常**：游戏窗口关闭/不存在时按热键 → **预期**：日志记「动作跳过：目标游戏窗口不存在」，不卡键、按住周期在该键抬起时正常关闭
- [x] **异常**：用切换键禁用热键后按已绑定的键 → **预期**：热键不触发、无异常；重新启用后一切正常（`HoldGuard.Stop()` 已清空按住周期与兜底定时器）
- [x] **异常**：按住某键期间切换到「卫戍协议」标签页（重建热键）→ **预期**：不卡键；新标签页的热键立即可用
